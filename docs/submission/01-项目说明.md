# 校园智办 / CampusPilot 项目说明

## 定位与目标用户
服务高校学生的校园事务助手。学生常遇到服务入口分散、材料要求难理解、重复填写与忘记后续节点的问题。CampusPilot将自然语言需求转为能核对、能修改、能追踪的办理路径。

## 主要场景
奖助学金申请、请假与销假、宿舍报修、校园活动报名。当前使用自制演示知识与虚构材料，不代表任何学校真实政策。

## 核心流程
用户描述事项 → Agent识别与检索 → 输出指南引用和清单 → 用户上传材料 → 视觉模型提取字段 → 草稿映射与人工修正 → 用户确认 → 保存任务 → 标记进度并创建站内提醒。

AI同时承担理解、检索规划和材料信息提取，输出作为后续表单和办理节点输入，贯穿主要服务链路。所有重要写操作由明确界面操作触发，不由模型擅自提交。

## 团队
高超、潘庆涛、郑宇豪，共三人。代码由AI协助实现，团队负责场景、产品决策、验证和答辩。报名组别、学校与学籍信息、指导教师、队名需由团队在报名系统确认并填入，不代填未知事实。
