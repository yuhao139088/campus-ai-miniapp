# 落地运营与增长规划

## 试点路径
1. 与一所学校或学院确认正式指南授权，建立来源、版本与审核责任人，替换演示知识。
2. 小范围邀请学生完成真实办事可用性测试，重点记录材料缺失、错误字段和无法回答的问题。
3. 在获准范围内接入身份与学校服务系统；任何申请提交、审批和收费必须保留校方授权边界。
4. 完成隐私政策、数据保留与删除、访问日志和内容安全，逐步开放。

## 可量化验证
统计完成一项事务的时间、补材料次数、表单修正率、有效引用率、任务完成率、模型失败率和每次办理模型成本。先建立基线，再比较改进；当前未开展真实用户实验，不填增长数字。

## 增长与运营
从新生入学、奖助学金申请季、活动报名等明确场景切入，通过校方认可的服务入口和线下演示招募。分享、收藏和微信订阅通知属于后续可选能力，当前不列为已上线。

## 商业与成本
优先探索学校/学院服务采购、知识库维护和系统集成服务；学生基础事务办理不预设收费。模拟权益仅说明可扩展接口，不构成收费方案。每次模型调用、OCR、云存储和网络成本均需在试点测量并设置预算与限流。

## 风险与边界
错误政策引用用版本审核和真实来源解决；OCR错误通过字段核对和留空策略降低；外部服务不可用时显式降级；个人材料限制采集并按权限隔离。具体部署域名、运维负责人、服务器IP、正式模型套餐和数据保留天数需在试点前由团队与学校确认。
