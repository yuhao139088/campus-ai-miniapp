# 创新点说明

1. **从答案到办理状态**：AI规划不止输出文字，同一runId关联材料、表单和任务，使后续操作承接先前理解。
2. **有依据、有边界的协作**：办理回答引用实际知识记录，材料字段保留原始值，缺失信息不编造；申请草稿必须人工核对后确认。
3. **真实能力状态可见**：实时AI、离线演示、模型错误降级、文字提取和图像OCR明确区分。避免演示效果掩盖模型/网络失败。
4. **规则可追溯**：微信小程序内导入个人学校资料，资格、材料与截止日期都回到通知原文，个人资料按学校/校区隔离。
5. **可演进的高校试点方案**：通过可替换模型、SQL知识库、身份和存储边界，允许后续按具体学校接入正式指南与授权系统。

以上为本项目产品与实现特点，不宣称全球首创、不虚构用户规模、竞品数据或商用成效。向量检索、校方审批对接、订阅推送和多校知识隔离属于下一阶段，不能列为已交付创新。
