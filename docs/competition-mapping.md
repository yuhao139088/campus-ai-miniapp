# 比赛规则与交付映射

目标为2026第九届传智杯AI微信小程序开发挑战赛，官方赛项id=10038。id=10037为AI WEB，不是本项目赛道。

| 评审维度 | 权重 | 本项目证据 |
|---|---|---|
| 技术实现 | 25% | 原生TS、Node API、SQL迁移、私有存储、Docker配置、测试 |
| AI融合 | 20% | Agent理解与检索规划、真实视觉OCR、结果进入表单任务 |
| 创新 | 20% | 从问题到办理状态、来源可追溯、人工确认与能力状态透明 |
| 场景与商业闭环 | 15% | 四类校园事务、任务追踪、学校试点与成本测量规划 |
| 体验与增长 | 10% | 原生入口、扫描与过程反馈、可编辑表单、站内提醒；增长能力作为规划 |
| 完整性与材料 | 10% | README、源码、迁移、测试、七类文档与演示脚本 |

七类材料见submission/01至07。不把尚未完成的分享、收藏、微信订阅推送、实际缴费或学校审批接入写成已上线。

团队规则：1–3名同校学生，指导教师不超过2名，具体组别按官方适用对象选择。团队三人姓名已提供，学校、学籍、组别和报名信息须由本人确认。

报名和省赛作品提交截止：2026-11-18。官网国赛作品截止写2026-12-27，但部分说明又写评审意见2027年1月底发布，时间存在不一致；以组委会后续正式通知为准，不擅自消除矛盾。评分表其他重复/比例矛盾也需报名时复核。

提交：建议ZIP不超过300MB，建议名称“第九届传智杯-AI小程序赛道-校园智办”。包含源码、七类材料、运行说明、实际演示视频、体验账号或二维码。不可将本地密钥、node_modules、探索资料、第三方技能缓存或真实用户资料打包。

官方规则来源：https://www.boxuegu.com/matchTrack/detail/?id=10038 。本地官方响应快照保存在私有AI交接，不随公共源码提交。
