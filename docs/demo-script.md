# 3分钟演示建议

1. 20秒：展示微信小程序首页，说明四类校园事务与演示学校知识。
2. 40秒：输入奖学金问题，观察处理中反馈、真实AI回答、知识引用与工具记录。
3. 35秒：选择自制虚构材料图片，展示真实图像识别结果。若模型服务失败明确展示错误，不用样本冒充OCR。
4. 35秒：生成表单，演示空白字段提醒、手工修正、确认后创建任务。
5. 25秒：任务勾选、进度变化、明日站内提醒。解释尚无微信订阅推送和校方审批接入。
6. 25秒：小程序资料库与原生页面说明架构、SQL持久化、隐私隔离与错误降级。

录屏前从干净的演示会话开始，检查实际AI模型与数据库状态。只录制微信小程序。演示时不得展示环境文件、CLI服务密钥、真实学籍或个人材料。待完成真机验收后再录最终参赛视频。
