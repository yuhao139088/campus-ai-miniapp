# CampusPilot 视觉系统

设计基于用户确定的“未来校园智能终端”：把校园建筑岛作为品牌场景，把四阶段办理轨道作为功能主线。

| 用途 | 色值 |
|---|---|
| 深夜校园底色 | #081021 |
| 工作面板 | #101E33 |
| 行动指引青绿 | #52E0BC |
| 结构边线 | #273851 |
| 主要正文 | #EEF5FF |
| 次要说明 | #9AACBF |

小程序采用系统中文字体、rpx布局、88rpx主要触控区域、安全区导航；使用状态反馈、扫描线与进度过渡，不依赖网页DOM动画组件。

单画布技能应用：锁定全局颜色、线宽、圆角和字号；七页概念板采用4列2行，390×844面板、40px间隔，禁止页面重叠。`assets/prompts/ui-board.txt`保存项目专用提示词。ShowAPI无AppKey模拟调用实际返回通用美食示例，并非本项目设计，不纳入项目素材。真实远程工作流仍需ShowAPI凭据。

自制临时校园插画和图标在Image-2.5服务商恢复前使用，详见资源来源清单。不能把临时绘制资产标记为AI生成。
